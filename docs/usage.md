# 使用指南

适合插件使用者与管理员：从工作台出图、在聊天中编辑图片、配置风格与发送结果。安装见 [README](../README.md#安装)，账号和模型准备见[平台配置](platforms.md)。

目录：[工作台](#工作台) · [图生图](#图生图) · [聊天命令](#聊天命令) · [风格预设](#风格预设) · [结果与日志](#结果与日志)

## 工作台

1. **绘图平台 → 添加平台**：选择类型，填写平台名称、密钥、服务地址与账号可用的模型；点击 **保存平台**，应出现该实例卡片。
2. **开始创作 → 文生图**：输入绘图描述，选择“绘图模型”和“风格预设”。平台名和模型名一起显示，便于区分多个账号。
3. 点击 **开始绘图**：任务在后台执行，页面不需要一直停在创作页。
4. **绘图任务**：按状态或模型、任务 ID、失败原因搜索，打开任务卡片查看结果。

没有配置默认模型时自动选择可用模型；预填模型并不代表账号已开通。可以在“偏好与预设”选择首选模型、有序备选与最多重试次数，初次使用不必修改高级参数。

### 发送到聊天

结果默认只在工作台显示，明确需要发送时请选择 **同时发送到聊天**，加载并选择当前实例已有的真实会话，页面优先显示会话名称。

## 图生图

在创作页切换 **图生图**，上传真实图片，再输入希望保留或修改的内容。参考图数量由所选模型决定。

- 文生图不能附带源图，图生图必须有真实源图。
- 智谱、RinkoAI NAI 以及其他明确不支持编辑的模型会提前拒绝。
- 可灵/Vidu 等要求公网原图 URL 的模型，不能直接使用网页上传或联动 Base64 入口；带原图 URL 的聊天适配器可保留该地址。

## 聊天命令

所有命令以 `/绘图` 开头，也可以使用 `/drawpic`。下文的 `<参数>` 需要替换为实际内容，`[参数]` 表示可选，不要输入尖括号或方括号。描述可以包含空格；风格名称按第一个空格分隔，建议使用不含空格的名称。

### 帮助、状态与模型

| 命令 | 用途 | 示例或说明 |
| --- | --- | --- |
| `/绘图` 或 `/绘图 帮助` | 查看命令帮助 | `/drawpic help` 效果相同 |
| `/绘图 状态` | 查看当前会话的模型、兼容模式、额度和最近任务 | 查询不会发起绘图 |
| `/绘图 模型` | 查看已启用平台的模型列表 | 每行格式为 `1. 平台名称/模型名称` |
| `/绘图 模型 <平台名称/模型名称>` | 保存当前会话的首选模型 | `/绘图 模型 OpenAI_Compatible/gpt-image-2` |
| `/绘图 模型 <索引>` | 按当前列表的编号切换模型 | `/绘图 模型 1` |

模型名称中的平台部分是你添加平台时填写的**实例名称**，不是固定的平台类型；例如实例叫 `openai`，就填写 `openai/gpt-image-2`。必须使用列表中的完整名称或有效索引，不能只写 `gpt-image-2`。索引从 1 开始，增删模型或启停平台后应重新查看列表；NAI 专属模型命令不支持索引，见下表。已有会话选择在升级时自动迁移，不需要重新逐群设置。

模型、兼容模式、NAI 模式与画师的设置会保存为当前会话偏好：群聊影响当前群，私聊影响当前用户；后续聊天绘图沿用，单次任务不修改工作台中的全局默认。开启权限管理后，只有插件配置中的管理员可以修改这些偏好或调整额度；未开启权限管理时不限制这些管理命令。查看类命令不要求管理员权限。

### 绘图与风格

| 命令 | 用途 | 示例 |
| --- | --- | --- |
| `/绘图 文生图 <描述>` | 强制按文字生成图片 | `/绘图 文生图 夜晚的海边灯塔，水彩插画` |
| `/绘图 图生图 <描述>` | 强制编辑真实源图 | `/绘图 图生图 保留人物，把背景改成樱花树林` |
| `/绘图 风格` | 列出已启用的风格预设及说明 | 在工作台添加预设后可用 |
| `/绘图 风格 <风格名称> <描述>` | 本次套用指定风格 | `/绘图 风格 水彩 一座森林小屋` |
| `/绘图 风格 默认 <描述>` | 本次套用工作台的默认风格 | 没有默认风格时保持原始描述 |
| `/绘图 风格 无 <描述>` | 本次不套用风格 | `/绘图 风格 无 雨后的城市` |

图生图命令需与图片一起发送，或回复包含图片的消息；可用张数由模型决定。文生图命令检测到真实图片时会提示切换模式，图生图找不到真实图片时会要求补图。风格命令自动判断：附带或引用真实图片时采用图生图，否则文生图。引用能力受适配器限制，见 [QQ 适配器说明](qq-adapters.md)。

上述绘图命令均可在描述后添加 `--反向 <反向提示词>`，英文形式为 `--negative <反向提示词>`；标记前后需要空格，反向内容放在命令末尾。需要在目标平台实例中开启“启用反向提示词”才会接受本次反向输入。

在“绘图平台 → 编辑平台”中，每个实例分别设置反向词开关，开启后可选填“默认反向提示词”。默认词会追加到本次输入后，与风格反向词按词条去重，保留首次出现的顺序和权重。NovelAI 默认开启，其余平台默认关闭。旧实例未保存开关时也使用对应平台的默认值。

关闭开关后，AI 工具、命令、工作台和 API 传入的反向词及平台默认反向词均被忽略。风格预设自己的正向、反向模板仍生效，`{negative_prompt}` 对应的本次输入会清空。开启平台的英文提示词改写时，最终反向内容也会改写；平台无独立反向字段时，再合并到正向提示词。备选模型使用各自实例的开关和默认词。

```text
/绘图 文生图 一座雪山 --反向 模糊，水印，文字
/绘图 图生图 保持人物，改为夜景 --negative blurry, watermark
/绘图 风格 水彩 一座被森林环绕的小木屋 --反向 低清晰度
```

在“偏好与预设 → 风格预设”添加名称、说明和正反向提示词模板。`{prompt}`、`{negative_prompt}` 分别替换本次提示词；没有占位符时自动追加。设置默认风格后，未指定风格的普通文生图、图生图、AI 绘图工具和插件 API 会自动套用；工作台默认选择“跟随默认风格”。需要跳过本次预设时，选择“不使用预设”、传入 `style="none"` 或使用 `/绘图 风格 无 <描述>`。风格只影响本次提示词，不改变会话模型或 NAI 数据集模式。

### OpenAI 兼容模式

| 命令 | 用途 |
| --- | --- |
| `/绘图 兼容模式` | 查看当前选择和可用模式 |
| `/绘图 兼容模式 <mode>` | 保存当前会话的 OpenAI 协议选择 |
| `/绘图 兼容模式 跟随` | 清除会话覆盖，跟随模型所在平台的配置 |

`<mode>` 支持 `auto`（自动判断）、`images_api`（图片接口）、`chat_completions`（标准聊天绘图接口）、`rinkoai`（RinkoAI NAI 兼容）。例如 `/绘图 兼容模式 chat_completions`。该设置只对 OpenAI / 兼容服务平台生效，`auto` 仍是显式会话设置，与“跟随平台配置”不同；RinkoAI NAI 暂不支持图生图。

### NovelAI / NovelAPI 专属命令

先在工作台添加并启用 NovelAI / NovelAPI 平台。当前会话已选中 NAI 模型时优先使用该模型，否则使用可用的默认 NAI 模型；这些命令不会调用 OpenAI 兼容平台上的同名模型。

| 命令 | 用途或示例 |
| --- | --- |
| `/绘图 nai` | 查看 NAI 模型、模式、画师、采样参数及用法 |
| `/绘图 nai 参数` | 查看采样和图生图参数；此命令只查询，参数在工作台修改 |
| `/绘图 nai 模型` | 查看 NAI 模型信息 |
| `/绘图 nai 模型 <平台名称/模型名称>` | 保存会话首选模型，如 `/绘图 nai 模型 novelai/nai-diffusion-4-5-full`；不接受短名或索引 |
| `/绘图 nai 模式` | 查看当前模式 |
| `/绘图 nai 模式 <mode>` | 保存会话模式，如 `/绘图 nai 模式 furry` |
| `/绘图 nai 模式 跟随` | 清除会话模式覆盖，跟随平台默认 |
| `/绘图 nai 画师` | 查看当前画师标签 |
| `/绘图 nai 画师 <标签>` | 保存完整标签串，如 `/绘图 nai 画师 artist:example_one, artist:example_two` |
| `/绘图 nai 画师 跟随` | 清除会话画师覆盖，跟随平台默认画师；不会清空平台默认配置 |
| `/绘图 nai 文生图 <描述>` | 强制 NAI 文生图 |
| `/绘图 nai 图生图 <描述>` | 强制 NAI 图生图，需一张真实源图 |
| `/绘图 nai <描述>` | 自动判断，有真实源图时图生图，否则文生图 |
| `/绘图 nai <mode> <描述>` | 仅本次使用指定模式，如 `/绘图 nai furry 一只在森林中散步的狐狸` |

模式支持 `anime`（动漫，也接受“动画”）、`furry`（兽人，也接受“福瑞”）、`background`（背景）。V3 的 Anime / Furry 会按模式切换对应模型，需提前启用相关模型；其他模型仍受平台能力限制。NAI 绘图同样支持末尾 `--反向` / `--negative`。模式与画师设置会持续生效，一次性模式命令不修改已保存偏好。

### 绘图额度管理

以下命令调整**当前平台、目标群聊或私聊用户、当前额度周期**的剩余次数，开启权限管理后仅管理员可用。查看当前会话额度请使用 `/绘图 状态`。

| 命令 | 用途 | 示例 |
| --- | --- | --- |
| `/绘图 设置 <范围> <ID> <数量>` | 将剩余次数设为指定值，可设为 0 | `/绘图 设置 群聊 673381211 50` |
| `/绘图 添加 <范围> <ID> <数量>` | 增加剩余次数，数量为正整数 | `/绘图 添加 用户 12345678 10` |
| `/绘图 减少 <范围> <ID> <数量>` | 减少剩余次数，数量为正整数 | `/绘图 减少 群聊 673381211 5` |
| `/绘图 次数 <操作> <范围> <ID> <数量>` | 等价的分组写法，操作为添加、减少或设置 | `/绘图 次数 设置 用户 12345678 10` |

范围填写 `群聊` 或 `用户`。群聊额度由该群共享，用户额度用于该用户的私聊；这里修改的剩余次数不会更改工作台配置的默认额度和周期。仅输入 `/绘图 次数` 会显示调整用法。官方 QQ 适配器应使用 Host 实际识别的群/用户 ID，不把 OpenID 擅自替换为数字 QQ 号。

### 英文与兼容别名

下列写法与中文命令等价，可与 `/drawpic` 前缀组合；不是额外的设置入口。

| 中文写法 | 等价别名 |
| --- | --- |
| `帮助`、`状态`、`模型`、`兼容模式` | `help`、`status`、`model`、`compatible-mode` |
| `文生图`、`图生图`、`风格` | `draw`（也接受“绘制”）、`edit`、`style` |
| `nai` | `novelai` |
| `次数`、`添加`、`减少`、`设置` | `times`、`add`、`remove`、`set` |
| 额度范围 `群聊`、`用户` | `群` / `group`、`私聊` / `user` / `private` |
| `nai 参数`、`nai 模型`、`nai 模式`、`nai 画师` | `nai params`、`nai model`、`nai mode`（也接受“风格” / `style`）、`nai artist` / `nai artists` |
| `nai 文生图`、`nai 图生图` | `nai draw`（也接受“绘制”）、`nai edit`（也接受“编辑”） |
| `风格 默认`、`风格 无` | `style default`、`style none` / `style plain`（也接受“原始”） |
| 兼容模式、NAI 模式/画师的 `跟随` | `默认` / `清空` / `default` / `unset` / `clear`，均表示清除会话覆盖 |

NAI 的 `帮助` / `help`、`状态` / `status` 与不带子命令的 `/绘图 nai` 显示相同信息。聊天中没有任务取消子命令；需要取消时在工作台的绘图任务中操作。


## 风格预设

在 **偏好与预设 → 风格预设** 添加风格名称、说明与模板。通用配置、审核配置、黑白名单和风格预设共用草稿，切换分类不丢内容。点击页面右下角的保存图标，一次保存四个分类；鼠标悬浮或键盘聚焦时显示“保存全部设置”标签。手机端底部操作区独立留位；离开整个设置页时仍会确认未保存修改。

### 两个占位符是什么

- **`{prompt}`**：本次输入的绘图描述。正向模板写 `水彩，{prompt}`，本次输入 `一只猫`，最终是 `水彩，一只猫`。
- **`{negative_prompt}`**：本次输入的反向提示词，即不希望出现的内容。反向模板写 `模糊，{negative_prompt}`，本次填写 `水印`，最终是 `模糊，水印`。

建议保留占位符，在前后添加固定风格词；不要把示例花括号替换成固定的绘图主题。删除占位符后，插件仍会把本次内容自动追加到模板末尾，并不会丢弃用户描述。NovelAI 的 `{{tag}}` 权重语法可保留。

没有反向输入或实例关闭反向词时，保留模板自己的反向词。开启时还会追加该实例的默认反向词，并对最终反向词去重。平台无独立反向字段时，按模型适配规则合并到提示词。风格不切换 NovelAI 数据集，也不修改会话模型。默认风格从已启用风格中选择，留空不自动套用。

反向模板为空或仅有 `{negative_prompt}` 占位符时，没有风格自带的反向内容；若实例也关闭反向词，最终反向词为空，AI 传入的反向内容同样会被忽略。

**恢复当前分类默认**只回填该分类，其他分类草稿保留；保存全部设置后才生效。保存失败会保留草稿。平台参数另在各平台编辑窗口点击“保存平台”，不会被这个按钮一起保存。

## 结果与日志

任务详情先显示 WebP 预览，点击 **查看原图** 按块读取原文件。宿主隔离页面仅提供原图预览，没有一键下载权限。

结果缓存可能被容量、时间或任务数量限制清理；旧任务也可能从未保存图片。保留的任务记录不保证图片仍可读，重要作品请及时另存。详见[缓存策略](configuration.md#缓存与保留期)。

在 **运行日志** 按任务 ID、级别查询。反馈问题请附任务 ID、版本和脱敏后的原因，不要提交密钥、完整图片 Base64 或迁移备份。

取消终止本地等待，不保证上游撤单、停止线程或停止收费。若显示结果待确认，请检查提供商原任务，不要因为等待结束就重新生图。
